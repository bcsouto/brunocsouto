# Marketplace de plugins · Bruno Corrêa Souto

Catálogo de plugins para o Claude (claude.ai, Cowork e Claude Code).

## Plugins

| Plugin | O que faz |
|---|---|
| [Coiote Místico](plugins/coiote-mistico) | Consulta de tarô Rider-Waite-Smith com selo SHA-256 verificável antes da escolha e prompt de imagem da tiragem no padrão MidasFlow |

## Como adicionar

No claude.ai: Personalizar, Plugins, Adicionar, Adicionar marketplace, e informe `bcsouto-hub/coiote-mistico`.

No Claude Code:

```bash
claude plugin marketplace add bcsouto-hub/coiote-mistico
claude plugin install coiote-mistico@brunocsouto
```
